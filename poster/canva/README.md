# Open these posters in Canva / 用 Canva 打开

Canva **cannot open HTML**. Use the PDF or PNG files in this folder.

Canva **不能直接打开 HTML**。请上传本文件夹里的 PDF 或 PNG。

---

## Easiest (free Canva) · 免费版最简单

1. Open [canva.com](https://www.canva.com) and click **Create a design**.
2. Choose **Custom size** → **297 × 420 mm** (A3) or **3508 × 4961 px**.
3. Click **Uploads** → upload:
   - `poster-1-registration-day.png`
   - `poster-2-required-documents.png`
4. Drag a PNG onto the page as the **background**.
5. Add new text boxes **on top** if you need to change wording.

Repeat for the second poster (File → Create new design, same size).

打开 Canva → 自定义尺寸 **297×420 mm** → 上传 PNG → 拖到画布当背景 → 需要改字时在上面再加文字框。

---

## More editable (Canva Pro) · 专业版可改字

1. In Canva: **File → Import files** (or Uploads).
2. Upload:
   - `poster-1-registration-day.pdf`
   - `poster-2-required-documents.pdf`
3. Open the imported PDF. Text and boxes are often editable.

打开 Canva 专业版 → **导入 PDF** → 文字通常可以直接点开修改。
